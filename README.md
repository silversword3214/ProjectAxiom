# Project Axiom

Project Axiom is a Minecraft utility/hack client.
It does **not** connect to Mojang, Microsoft, or any official servers.

## Installation

1. Make sure you have **Fabric Loader** installed for your Minecraft version.
2. Place the compiled JAR of Project Axiom into the `mods` folder.
3. Launch Minecraft with Fabric, and the client modules will be loaded automatically.
